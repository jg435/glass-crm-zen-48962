Autonomous AI Sales Assistant Platform - Project Report

1. Challenge We Have Tackled

B2B sales reps close only 2-3 deals monthly while drowning in administrative work. Sales managers consistently report teams spending hours on LinkedIn research, email crafting, CRM data entry, and missed follow-ups. We built an AI system where specialized agents handle grunt work while humans control relationship building. The core idea: talk to your CRM naturally—"Hey Sarah, add John from Acme Corp as a lead" while driving between meetings.

Five specialized agents run continuously: one monitors email for high-intent replies ("Can we schedule a call?"), another researches new leads with company data and recent news, one schedules follow-ups based on pipeline status, and a meeting co-pilot provides real-time suggestions during sales calls. Everything AI-drafted gets queued for approval—review, tweak, send. This provides 10x speed while maintaining control over client relationships.

2. Tools / ML Models We Have Used

Gemini 2.0 Flash powers real-time meeting assistance with sub-200ms latency and direct audio processing—critical for natural sales conversation flow. Gemini 1.5 Pro handles complex reasoning tasks with its 1M token context window, analyzing entire company websites, email threads, and meeting notes simultaneously to draft personalized emails that resonate.

Infrastructure runs on Supabase: Edge Functions (Deno) deploy instantly and scale automatically, PostgreSQL with Row Level Security ensures data isolation per organization. Frontend uses React + TypeScript for type-safe state management and Tailwind CSS for consistent UI. Custom wake word detection uses Web Speech API. External integrations: Firecrawl for JavaScript-heavy website scraping, Tavily for company research, Google Calendar API for meeting booking.

3. What Has Worked Well With These Tools?

Gemini Flash 2.0's voice latency feels like talking to a person—beta testers forgot they were conversing with AI. Context retention is excellent; it remembers "that prospect from yesterday" without re-prompting. Pro's email quality impressed users: "I used to spend 30 minutes on cold emails. Now AI does 80%, I add personal touch." It handles 50+ page PDFs plus email history while extracting relevant personalization details.

Supabase delivered zero downtime since launch. Edge Functions deploy globally in seconds without DevOps expertise. RLS policies eliminate data isolation concerns—customer data is database-level sandboxed. Web Speech API surprised us with accurate wake word detection across accents and noisy environments after confidence tuning. TypeScript caught compile-time bugs that would've been production nightmares, enabling confident feature shipping.

4. What Was Challenging?

Voice recognition false triggers ("Hey, Sara" vs. "Hey Sarah") and premature cutoffs plagued early versions. Solution: sliding confidence thresholds adapting to background noise plus 2-second silence buffers. Natural language parsing required handling variations like "Add John Smith who works at Acme" vs. "New lead, John from Acme." Multi-pattern matchers with fallbacks and explicit database verification now confirm saves before success messages.

Critical bug: system claimed "Lead created!" before database writes completed, destroying user trust when later queries found nothing. Fixed with immediate read-back verification after every write—slight latency increase worth the reliability gain. Agent orchestration required locking mechanisms to prevent duplicate email drafts when multiple agents triggered simultaneously. Deduplication layer handles repeated external triggers (email webhooks).

Stateless Edge Functions required explicit conversation history storage and reload per request for context maintenance. Balancing autonomy vs. control took iterations—settled on automatic research/drafting with human approval for customer-facing communications. Review tab queues drafts for batch approval during downtime, avoiding constant interruptions.

5. How Have We Spent Our Time?

Voice system (30%): Recording hundreds of wake word variations across environments, tuning confidence thresholds, implementing silence detection, handling edge cases (coughing mid-command). Gemini Live integration was straightforward; surrounding UX for natural voice interaction was complex.

AI agents (25%): 50+ prompt iterations for email drafting agent to eliminate robotic tone. Orchestrator development—determining trigger conditions, preventing duplicates, graceful failure handling. Database (15%): Learning PostgreSQL RLS, schema design for leads/emails/meetings/actions balancing flexibility with referential integrity, index optimization for heavy queries.

Frontend (15%): Iterating dashboard design—early versions overwhelmed users with data, simplified to essential tiles (today's tasks, high-priority leads, approval queue). API integrations (10%): OAuth flows, token refresh, scope permissions, error handling for Google Calendar/Firecrawl/Tavily. Testing/optimization (5%): Fixed persistence bug, batched API calls, cached research data, trimmed excessive context in Gemini requests after cost audit.
